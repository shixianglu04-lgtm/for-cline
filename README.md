# 深圳机器人行业实习岗位调研（应用工程师 / 技术支持 / 产品经理）

> 采集时间：2026-10-09（UTC）｜ 目标：深圳 + 机器人行业 + **仅实习岗位**，覆盖三类岗位
> 交付物：`jobs_table.md` / `jobs_table.csv`（≥10 个岗位）+ 证据与采集方法说明

## 交付物清单

| 文件 | 内容 |
| --- | --- |
| `jobs_table.md` | 最终岗位表（Markdown，含岗位要求/经验门槛/毕业时间限制） |
| `jobs_table.csv` | 同表 CSV（便于导入表格软件） |
| `data/*.json` | 原始结构化采集数据（含 source_url / evidence / collected_at） |
| `notes/method.md` | 采集方法与各渠道可用性（含被拦截渠道的证据） |
| `notes/evidence.md` | 逐岗位原文证据摘录（可复核） |
| `tools/*.py` | 采集脚本（可复现） |

## 字段定义

- **岗位要求**：招聘页"任职要求/职位要求"原文要点
- **经验门槛**：页面标注的工作经验要求（实习岗位常见"不限经验"，个别要求项目/竞赛/实习经历）
- **毕业时间限制**：届别（如 2027 届）、毕业时间区间、在校生身份、可实习时长与每周出勤天数

## 采集方法（概览）

1. **实习僧**（Nuxt SSR，可直接抓取）：`tools/sxs_scrape.py`
2. **职友集**（聚合 BOSS直聘/猎聘/实习僧/智联 等，列表页明文，详情页内嵌原始来源 URL）：`tools/jobui_scrape.py`
3. **企业官网/官方招聘系统**（MokaHR / 北森 / 自建）：见 `notes/method.md`
4. **BOSS直聘 / 猎聘**：见 `notes/method.md` 的可用性结论与绕过尝试记录
